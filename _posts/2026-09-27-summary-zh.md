### [Reladraw：让用户决定布局的开源图表语言](https://github.com/reladraw/reladraw) ⭐️ 6.0/10

Reladraw 是一个开源图表语言项目，作者在 Hacker News 的 Show HN 帖中表示，它旨在避免 Mermaid、Graphviz 这类自动布局语言无法控制外观的问题，同时比 Draw.io 这类手动绘图软件更省时、也更便于 AI agent 操作。其核心做法是保留用户对图表相对位置的控制，而不是完全交给自动布局。项目在 GitHub 上提供免安装的浏览器 playground、npm 安装方式，以及可用于 Claude 等 agent 的 skill。目前仍属早期阶段：有评论者反馈边路由和 Safari 下切换主题存在 bug，也有人质疑 README 是 LLM 生成的。

hackernews · jpwalsh234 · 9月26日 17:10 · [社区讨论](https://news.ycombinator.com/item?id=49858513)

**「背景」** 现有的代码化图表工具大多走两条路：Mermaid、Graphviz 一类依靠自动布局决定节点位置，用户难以精确控制最终成图；Draw.io 一类图形工具控制力强，但手工操作耗时，也不便让 AI agent 直接修改。Reladraw 试图结合两者，用声明式图表语言保留对相对位置的显式控制，并同时面向人类用户和编码 agent。

**「影响」** 对于认为 Mermaid、Graphviz 在流程图上位置控制不足的开发者，Reladraw 提供了一条通过 npm 或浏览器 playground 直接用相对定位描述图表的路径，并附带可接入 Claude 等 agent 的 skill；但由于评论者已报告边路由不智能、Safari 切换主题后示例可读性变差等问题，现阶段更适合试用评估而非直接用于生产文档。

**「社区讨论」** 有评论者认为 Mermaid 在时序图、甘特图等固定布局场景表现良好，但在位置至关重要的流程图上很差，而 Reladraw 的相对定位“大概已经够用”；另有评论者称图表是人与 agent 之间对齐心智模型的高带宽方式，因此有意把它加入 agent 可用的绘图工具清单。也有评论者因 README 看起来像 LLM 生成而表示不再继续了解，以及有用户报告了具体 bug。
